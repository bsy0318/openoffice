# Модели ИИ и настройки

## Где находятся настройки

Откройте **Настройки** из строки в левом нижнем углу «Главной» и выберите **ИИ**. Первое, что вы увидите, — подключение по подписке. Большинству больше ничего не нужно, и о нём есть отдельная статья: [Подключение по подписке](help://subscription).

Всё, для чего нужен ключ, находится в разделе **Дополнительно** внизу той же страницы. Он остаётся свёрнутым, пока вы его не откроете.

## По умолчанию: ваша подписка

- Параметр **Используемый ИИ** сначала установлен на **Автоматически**: сначала подключённая подписка Claude, затем Codex.
- Автоматический режим никогда не выбирает то, что стоит дополнительных денег. API-ключ используется, только пока вы сами выбираете этого провайдера в списке **Используемый ИИ**.
- Список моделей внизу каждой панели ИИ показывает сначала подписки, а затем провайдеров с ключом, настройку которых вы завершили. У подписки пункт **Модель по умолчанию** означает стандартную модель этой подписки.

## API-ключи (Дополнительно ▸ Модель ИИ)

Для тех, кто предпочитает платить провайдеру напрямую или запускает собственную модель.

- Выберите значение в поле **Провайдер**, введите **API-ключ** (и **Базовый URL**, если провайдеру он нужен), выберите значение в поле **Модель** и нажмите **Сохранить**. В списке есть серверы, совместимые с OpenAI, Anthropic, Gemini, DeepSeek, DashScope (qwen), Atlas Cloud и другие.
- Список **Провайдер** здесь определяет только то, чьи поля показаны на экране. Он не меняет, какой ИИ используется; это всегда решает **Используемый ИИ**. Если сохранённый провайдер сейчас не используется, вверху появляется кнопка **Использовать этот ИИ**; нажатие выбирает его в пункте **Используемый ИИ**.
- Чаты через провайдера с ключом используют ваш собственный ключ, и плату за них берёт этот провайдер.
- Ключи сохраняются в файле настроек приложения на этом компьютере и отправляются только в заголовках запросов.
- **Проверить подключение**: убеждается, что адрес доступен и модель видна, до сохранения.
- Базовый URL может содержать путь и строку запроса (в стиле шлюза); путь конечной точки добавляется корректно.
- Для серверов, которые вы запускаете сами, можно сохранить несколько **эндпоинтов** и переключаться между ними в любой момент.
- **Исполняемый файл Codex** нужен только для программы Codex, установленной в нестандартное место. Оставьте поле пустым, и программа найдётся автоматически.

## Какой функции что нужно

| Функция                                                     | На чём работает                                                                                                                                                                                                               |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Чат и правка в панели ИИ                                    | Ваша подписка или провайдер с ключом, которого вы выбрали сами.                                                                                                                                                               |
| Понимание изображения                                       | ИИ, с которым вы общаетесь, сам смотрит на изображение. Дополнительный ключ не нужен. В разделе «Дополнительно» можно выбрать отдельного провайдера для анализа.                                                              |
| Создание изображения                                        | **В этой версии — только с ключом.** Настройте провайдера изображений в разделе Дополнительно ▸ Медиа и поиск ИИ. Без него генерация изображений недоступна, и Slides использует вместо этого изображения, найденные поиском. |
| Анализ видео и аудио                                        | Провайдер с ключом, который поддерживает видео, выбранный в разделе Дополнительно ▸ Медиа и поиск ИИ.                                                                                                                         |
| Поиск в вебе и поиск изображений, чтение страницы по адресу | По умолчанию бесплатно, без ключа. Ключ поискового провайдера необязателен.                                                                                                                                                   |
| Поиск по вашим собственным файлам                           | Работает на этом компьютере. Переранжирование результатов через внешнюю службу необязательно и по умолчанию выключено.                                                                                                        |

В разделе **Дополнительно ▸ Медиа и поиск ИИ** ключ и базовый URL провайдера вводятся один раз и используются всеми функциями, которые работают через этого провайдера.

## Когда изменения вступают в силу

- Смена модели и адреса применяется сразу; уже идущий разговор продолжает использовать прежнюю конфигурацию до следующего захода.
