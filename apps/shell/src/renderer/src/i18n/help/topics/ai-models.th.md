# โมเดล AI และการตั้งค่า

## การตั้งค่าอยู่ที่ไหน

เปิด **การตั้งค่า** จากแถวที่มุมล่างซ้ายของหน้าแรก แล้วเลือก **AI** สิ่งแรกที่เห็นคือการเชื่อมต่อการสมัครสมาชิก ซึ่งเพียงพอแล้วสำหรับคนส่วนใหญ่ และมีบทความของตัวเอง: [การเชื่อมต่อการสมัครสมาชิก](help://subscription)

ทุกอย่างที่ต้องใช้คีย์อยู่ใต้ **ขั้นสูง** ที่ด้านล่างของหน้าเดียวกัน และจะปิดอยู่จนกว่าคุณจะเปิดเอง

## ค่าเริ่มต้น: การสมัครสมาชิกของคุณ

- **AI ที่ใช้** เริ่มต้นที่ **อัตโนมัติ**: ใช้การสมัครสมาชิก Claude ที่เชื่อมต่ออยู่ก่อน แล้วจึงเป็น Codex
- อัตโนมัติจะไม่เลือกสิ่งที่มีค่าใช้จ่ายเพิ่ม คีย์ API จะถูกใช้เฉพาะช่วงที่คุณเลือกผู้ให้บริการรายนั้นเองใน **AI ที่ใช้**
- รายการโมเดลที่ด้านล่างของแผง AI แต่ละแผงจะแสดงการสมัครสมาชิกก่อน ตามด้วยผู้ให้บริการแบบใช้คีย์ที่คุณตั้งค่าเสร็จแล้ว ส่วน **โมเดลเริ่มต้น** ใต้การสมัครสมาชิกคือโมเดลมาตรฐานของการสมัครสมาชิกนั้น

## คีย์ API (ขั้นสูง ▸ โมเดล AI)

สำหรับผู้ที่ต้องการจ่ายเงินให้ผู้ให้บริการโดยตรง หรือใช้โมเดลของตัวเอง

- เลือก **ผู้ให้บริการ** กรอก **คีย์ API** ของรายนั้น (และ **Base URL** หากผู้ให้บริการต้องใช้) เลือก **โมเดล** แล้วกด **บันทึก** ในรายการมีทั้งเซิร์ฟเวอร์ที่เข้ากันได้กับ OpenAI, Anthropic, Gemini, DeepSeek, DashScope (qwen), Atlas Cloud และอื่น ๆ
- รายการ **ผู้ให้บริการ** ตรงนี้กำหนดเพียงว่าจะแสดงช่องกรอกของรายใดบนหน้าจอ ไม่ได้เปลี่ยน AI ที่กำลังใช้อยู่ ซึ่งกำหนดโดย **AI ที่ใช้** เสมอ หากผู้ให้บริการที่บันทึกไว้ไม่ใช่ AI ที่กำลังใช้อยู่ จะมีปุ่ม **ใช้ AI นี้** แสดงด้านบน กดแล้วผู้ให้บริการนั้นจะกลายเป็น **AI ที่ใช้**
- การสนทนาผ่านผู้ให้บริการแบบใช้คีย์จะใช้คีย์ของคุณเอง และผู้ให้บริการรายนั้นจะเรียกเก็บค่าบริการจากคุณ
- คีย์ถูกเก็บไว้ในไฟล์การตั้งค่าของแอปบนเครื่องนี้ และส่งไปเฉพาะในส่วนหัวของคำขอ
- **ทดสอบการเชื่อมต่อ**: ตรวจว่าปลายทางเข้าถึงได้และมองเห็นโมเดลหรือไม่ ก่อนบันทึก
- base URL อาจมีพาธและ query string ติดมาด้วย (แบบเกตเวย์) และพาธของปลายทางจะถูกต่อท้ายอย่างถูกต้อง
- สำหรับเซิร์ฟเวอร์ที่คุณดูแลเอง บันทึก **ปลายทาง** ไว้ได้หลายรายการ และสลับใช้ได้ทุกเมื่อ
- **ไฟล์ปฏิบัติการ Codex** มีไว้เฉพาะกรณีที่ติดตั้งโปรแกรม Codex ไว้ในตำแหน่งที่ไม่ปกติ ถ้าเว้นว่างไว้ ระบบจะค้นหาโปรแกรมให้อัตโนมัติ

## ฟีเจอร์ไหนต้องใช้อะไร

| ฟีเจอร์                                             | ทำงานด้วยอะไร                                                                                                                                                               |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| การสนทนาและการแก้ไขในแผง AI                         | การสมัครสมาชิกของคุณ หรือผู้ให้บริการแบบใช้คีย์ที่คุณเลือกเอง                                                                                                               |
| การทำความเข้าใจภาพ                                  | AI ที่คุณกำลังสนทนาด้วยจะดูภาพเอง ไม่ต้องใช้คีย์เพิ่ม และเลือกผู้ให้บริการวิเคราะห์แยกต่างหากได้ใต้ ขั้นสูง                                                                 |
| การสร้างภาพ                                         | **ในเวอร์ชันนี้ใช้ได้ด้วยคีย์เท่านั้น** ตั้งค่าผู้ให้บริการสร้างภาพใต้ ขั้นสูง ▸ สื่อ AI และการค้นหา ถ้าไม่ได้ตั้งค่าไว้ จะสร้างภาพไม่ได้ และ Slides จะใช้ภาพที่ค้นหาเจอแทน |
| การวิเคราะห์วิดีโอและเสียง                          | ผู้ให้บริการแบบใช้คีย์ที่รองรับวิดีโอ ซึ่งเลือกได้ใต้ ขั้นสูง ▸ สื่อ AI และการค้นหา                                                                                         |
| การค้นหาเว็บและค้นหาภาพ รวมถึงการอ่านหน้าจากที่อยู่ | ใช้ฟรีเป็นค่าเริ่มต้น ไม่ต้องมีคีย์ ส่วนคีย์ของผู้ให้บริการค้นหาจะใส่หรือไม่ก็ได้                                                                                           |
| การค้นหาภายในไฟล์ของคุณเอง                          | ทำงานบนเครื่องนี้ การจัดลำดับผลลัพธ์ใหม่ผ่านบริการภายนอกเป็นตัวเลือกเสริม และปิดอยู่เป็นค่าเริ่มต้น                                                                         |

ใต้ **ขั้นสูง ▸ สื่อ AI และการค้นหา** คีย์และ Base URL ของผู้ให้บริการกรอกเพียงครั้งเดียว แล้วใช้ร่วมกันในทุกฟีเจอร์ที่ใช้ผู้ให้บริการรายนั้น

## การเปลี่ยนแปลงมีผลเมื่อไร

- การเปลี่ยนโมเดลและปลายทางมีผลทันที ส่วนบทสนทนาที่กำลังดำเนินอยู่จะยังใช้การตั้งค่าเดิมไปจนถึงรอบถัดไป
