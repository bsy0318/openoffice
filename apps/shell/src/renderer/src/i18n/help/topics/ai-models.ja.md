# AI モデルと設定

## 設定の場所

ホームの左下の行から **設定** を開き、**AI** を選びます。最初に表示されるのはサブスクリプションの接続です。ほとんどの人はこれだけで足り、専用の記事があります：[サブスクリプションの接続](help://subscription)。

キーが必要なものは、すべて同じページのいちばん下にある **詳細設定** の中にあります。開くまでは閉じたままです。

## 既定はサブスクリプション

- **使用する AI** は、最初は **自動** です。接続済みの Claude のサブスクリプションが先で、次が Codex です。
- 自動が、追加の料金がかかるものを選ぶことはありません。API キーは、**使用する AI** でそのプロバイダーをご自身で選んでいる間だけ使われます。
- 各 AI パネルの下部にあるモデル一覧には、まずサブスクリプションが、続いて設定を終えたキー方式のプロバイダーが表示されます。サブスクリプションの下の **既定のモデル** は、そのサブスクリプションの標準モデルです。

## API キー（詳細設定 ▸ AIモデル）

プロバイダーに直接料金を支払いたい人や、自分で用意したモデルを動かしたい人のための場所です。

- **プロバイダー** を選び、その **APIキー** を入力し（プロバイダーが必要とする場合は **Base URL** も）、**モデル** を選んでから **保存** を押します。一覧には、OpenAI 互換サーバー、Anthropic、Gemini、DeepSeek、DashScope（qwen）、Atlas Cloud などがあります。
- ここの **プロバイダー** の一覧は、画面にどのプロバイダーの入力欄を表示するかを決めるだけです。使用中の AI は変わりません。それを決めるのは常に **使用する AI** です。保存したプロバイダーが使用中の AI でないときは、上部に **この AI を使う** が表示されます。押すとそのプロバイダーが **使用する AI** になります。
- キー方式のプロバイダーでの会話はご自身のキーを使い、料金はそのプロバイダーから請求されます。
- キーはこのアプリの設定ファイルに保存され、リクエストのヘッダーにだけ送出されます。
- **接続テスト**：保存する前に、エンドポイントへの到達性とモデルの見える範囲を確認できます。
- ベース URL にはパスとクエリ文字列を含められるので（ゲートウェイ形式）、エンドポイントのパスは正しく連結されます。
- 自分で運用するサーバーについては、複数の **エンドポイント** を保存しておき、いつでも切り替えられます。
- **Codex 実行ファイル** は、Codex プログラムを通常とは違う場所にインストールした場合にだけ使います。空欄のままにすると、プログラムは自動的に検出されます。

## 機能ごとに必要なもの

| 機能                                             | 何で動くか                                                                                                                                                                              |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AI パネルでの会話と編集                          | サブスクリプション、またはご自身で選んだキー方式のプロバイダー。                                                                                                                        |
| 画像の理解                                       | 会話中の AI が画像を直接見ます。追加のキーは不要です。解析用のプロバイダーを別に選ぶこともでき、詳細設定で指定します。                                                                  |
| 画像の生成                                       | **このバージョンではキーでのみ動きます。** 詳細設定 ▸ AI メディアと検索 で画像プロバイダーを設定します。設定がなければ画像生成は使えず、Slides は代わりに検索で見つけた画像を使います。 |
| 動画と音声の解析                                 | 動画に対応したキー方式のプロバイダー。詳細設定 ▸ AI メディアと検索 で選びます。                                                                                                         |
| Web 検索と画像検索、アドレスからのページ読み取り | 既定では無料で、キーは不要です。検索プロバイダーのキーは任意です。                                                                                                                      |
| 自分のファイル内の検索                           | このマシンで動きます。結果を外部サービスで並べ替え直す機能は任意で、既定ではオフです。                                                                                                  |

**詳細設定 ▸ AI メディアと検索** では、プロバイダーのキーと Base URL を一度入力すれば、そのプロバイダーを使うすべての機能で共有されます。

## 変更が反映されるタイミング

- モデルとエンドポイントの変更はすぐに反映されます。進行中の会話は、次の応答まで古い設定を使います。
