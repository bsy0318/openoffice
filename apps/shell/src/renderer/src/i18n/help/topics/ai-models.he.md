# מודלים של AI והגדרות

## איפה ההגדרות

פתחו את **הגדרות** מהשורה שבפינה השמאלית-תחתונה של הבית ובחרו **AI**. הדבר הראשון שתראו הוא חיבור המינוי. זה כל מה שרוב האנשים צריכים, ויש לו פרק משלו: [חיבור מינוי](help://subscription).

כל מה שדורש מפתח נמצא תחת **מתקדם**, בתחתית אותו עמוד. הוא נשאר סגור עד שפותחים אותו.

## ברירת המחדל: המינוי שלכם

- **ה-AI שבשימוש** מתחיל במצב **אוטומטי**: קודם מינוי Claude מחובר, ואחריו Codex.
- המצב האוטומטי לעולם אינו בוחר במשהו שעולה כסף נוסף. במפתח API משתמשים רק כל עוד אתם בוחרים בספק הזה בעצמכם תחת **ה-AI שבשימוש**.
- רשימת המודלים שבתחתית כל חלונית AI מציגה קודם את המינויים, ואחריהם את הספקים עם מפתח שסיימתם להגדיר. תחת מינוי, **מודל ברירת מחדל** הוא המודל הרגיל של אותו מינוי.

## מפתחות API (מתקדם ▸ מודל AI)

למי שמעדיף לשלם ישירות לספק, או להריץ מודל משלו.

- בחרו **ספק**, הזינו את **מפתח API** שלו (וגם **Base URL** כשהספק דורש זאת), בחרו **מודל**, ואז לחצו **שמירה**. הרשימה כוללת שרתים תואמי OpenAI, Anthropic, Gemini, DeepSeek, DashScope (qwen), Atlas Cloud ועוד.
- רשימת **ספק** שכאן קובעת רק של איזה ספק השדות שמוצגים על המסך. היא אינה משנה באיזה AI משתמשים; את זה קובע תמיד **ה-AI שבשימוש**. אם ספק ששמרתם אינו ה-AI שבשימוש, מופיע למעלה **שימוש ב-AI הזה**; לחיצה עליו בוחרת בו בתור **ה-AI שבשימוש**.
- שיחות דרך ספק עם מפתח משתמשות במפתח שלכם, והספק הזה מחייב אתכם עליהן.
- המפתחות נשמרים בקובץ ההגדרות של האפליקציה במחשב הזה ונשלחים רק בכותרות הבקשה.
- **בדיקת חיבור**: אימות שהנקודה נגישה ושהמודלים גלויים לפני השמירה.
- ל- Base URL יכול להיות גם נתיב ומחרוזת שאילת (בסגנון gateway); נתיבי נקודות הקצה מתווספים בצורה נכונה.
- לשרתים שאתם מריצים בעצמכם אפשר לשמור כמה **נקודות קצה** ולעבור ביניהן בכל עת.
- **קובץ ההפעלה של Codex** מיועד רק לתוכנת Codex שהותקנה במקום לא שגרתי. השאירו אותו ריק והתוכנה תימצא אוטומטית.
