# AI 模型与设置

## 设置在哪里

点主屏左下角的那一行打开**设置**，选择 **AI**。最先看到的是订阅连接。大多数人只需要这一项，它有专门的一篇说明：[订阅连接](help://subscription)。

所有需要填密钥的内容都在同一页底部的**高级**里。不展开的话，它一直是收起的。

## 默认：你的订阅

- **使用的 AI**一开始是**自动**：优先用已连接的 Claude 订阅，其次是 Codex。
- 自动绝不会选任何要额外花钱的方式。只有当你自己在**使用的 AI**里选中某个服务商时，才会用到 API 密钥。
- 每个 AI 面板底部的模型列表先列出订阅，然后是你已经配置完成的密钥服务商。订阅下面的**默认模型**是该订阅的标准模型。

## API 密钥（高级 ▸ AI 模型）

适合想直接向服务商付费，或者想运行自己的模型的人。

- 选择**模型服务商**，填入它的 **API Key**（服务商需要时还要填 **Base URL**），选好**模型**，然后点**保存**。列表里有 OpenAI 兼容服务器、Anthropic、Gemini、DeepSeek、DashScope（qwen）、Atlas Cloud 等。
- 这里的**模型服务商**列表只决定屏幕上显示哪一家的输入项，并不改变正在使用的 AI；那始终由**使用的 AI**决定。保存的服务商不是正在使用的 AI 时，上方会出现**使用此 AI**；点击后，该服务商即成为**使用的 AI**。
- 使用密钥服务商的对话用的是你自己的密钥，费用由该服务商向你收取。
- 密钥保存在本机的应用设置文件里，发送时只进请求头。
- **测试连接**：保存前可测试端点连通与模型可见性。
- base URL 支持带路径与查询串（如网关地址），App 会正确拼接端点路径。
- 对于自己运行的服务器，可以保存多个**端点**，随时切换。
- **Codex 可执行文件**只在 Codex 程序装在不常见的位置时才需要填。留空时会自动找到该程序。

## 各项功能需要什么

| 功能                                 | 靠什么运行                                                                                                                    |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| AI 面板里的对话与编辑                | 你的订阅，或你自己选中的密钥服务商。                                                                                          |
| 看懂图片                             | 正在和你对话的 AI 自己看图，不需要额外的密钥。也可以在“高级”里另选一个解析服务商。                                            |
| 生成图片                             | **在这个版本里只能用密钥。** 在 高级 ▸ 生图、媒体与搜索 里配置生图服务商。没有配置时无法生成图片，Slides 会改用搜索到的图片。 |
| 视频与音频解析                       | 支持视频的密钥服务商，在 高级 ▸ 生图、媒体与搜索 里选择。                                                                     |
| 网络搜索、图片搜索与通过网址读取页面 | 默认免费，不需要密钥。搜索服务商的密钥可填可不填。                                                                            |
| 在自己的文件里搜索                   | 在本机运行。通过外部服务对结果重新排序是可选功能，默认关闭。                                                                  |

在**高级 ▸ 生图、媒体与搜索**里，同一服务商的密钥和 Base URL 只需填一次，所有用到该服务商的功能共用。

## 何时生效

- 模型与端点改动即时生效；正在进行的对话继续用旧配置直到下一轮。
