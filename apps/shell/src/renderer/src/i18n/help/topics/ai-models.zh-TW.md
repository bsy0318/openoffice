# AI 模型與設定

## 設定在哪裡

按一下首頁左下角的那一列開啟**設定**，然後選擇 **AI**。最先看到的是訂閱連線。大多數人只需要這一項，它另有專文說明：[訂閱連線](help://subscription)。

所有需要填金鑰的項目，都在同一頁最底下的**進階**裡。在你展開之前，它會一直保持收合。

## 預設：你的訂閱

- **使用的 AI**一開始是**自動**：優先使用已連線的 Claude 訂閱，其次是 Codex。
- 自動絕不會選用任何要額外花錢的方式。只有當你自己在**使用的 AI**裡選了某個服務商，才會用到 API 金鑰。
- 每個 AI 面板底部的模型清單會先列出訂閱，接著是你已經設定完成的金鑰服務商。訂閱底下的**預設模型**是該訂閱的標準模型。

## API 金鑰（進階 ▸ AI 模型）

適合想直接付費給服務商，或是想執行自己的模型的人。

- 選擇**模型服務商**，填入它的 **API Key**（服務商需要時還要填 **Base URL**），選好**模型**，再按**儲存**。清單涵蓋 OpenAI 相容伺服器、Anthropic、Gemini、DeepSeek、DashScope（qwen）、Atlas Cloud 等。
- 這裡的**模型服務商**清單只決定畫面上顯示哪一家的欄位，並不會改變目前使用的 AI；那一律由**使用的 AI**決定。儲存的服務商不是目前使用的 AI 時，上方會出現**使用此 AI**；按下後，該服務商就會成為**使用的 AI**。
- 透過金鑰服務商進行的對話用的是你自己的金鑰，費用由該服務商向你收取。
- 金鑰儲存在本機的應用程式設定檔中，傳送時只放在請求標頭裡。
- **測試連線**：在儲存前先確認端點可連線且模型可見。
- Base URL 可以帶上路徑與查詢字串（閘道形式）；端點路徑會正確地接在其後。
- 如果是你自己架設的伺服器，可以儲存多個**端點**，隨時切換。
- **Codex 可執行檔**只有在 Codex 程式裝在不尋常的位置時才需要填寫。留空的話，會自動找到該程式。

## 各項功能需要什麼

| 功能                               | 靠什麼運作                                                                                                                    |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| AI 面板中的對話與編輯              | 你的訂閱，或是你自己選用的金鑰服務商。                                                                                        |
| 看懂圖片                           | 正在和你對話的 AI 會自己看圖，不需要額外的金鑰。也可以在「進階」裡另外選一個解析服務商。                                      |
| 產生圖片                           | **在這個版本裡只能用金鑰。** 請在 進階 ▸ 生圖、媒體與搜尋 設定生圖服務商。沒有設定時無法產生圖片，Slides 會改用搜尋到的圖片。 |
| 影片與音訊解析                     | 支援影片的金鑰服務商，在 進階 ▸ 生圖、媒體與搜尋 中選擇。                                                                     |
| 網路搜尋、圖片搜尋與以網址讀取頁面 | 預設免費，不需要金鑰。搜尋服務商的金鑰可填可不填。                                                                            |
| 在自己的檔案裡搜尋                 | 在本機執行。透過外部服務將結果重新排序是選用功能，預設關閉。                                                                  |

在**進階 ▸ 生圖、媒體與搜尋**裡，同一家服務商的金鑰與 Base URL 只需要填一次，所有用到該服務商的功能都會共用。

## 變更何時生效

- 模型與端點的變更立即生效；進行中的對話會沿用舊的設定，直到它的下一輪為止。
