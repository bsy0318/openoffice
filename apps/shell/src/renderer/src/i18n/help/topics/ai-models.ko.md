# AI 모델과 설정

## 설정이 있는 곳

홈 왼쪽 아래 줄을 눌러 **설정**을 열고 **AI**를 고릅니다. 먼저 보이는 것은 구독 연결입니다. 대부분은 이것만 있으면 되고, 따로 설명한 글이 있습니다. [구독 연결](help://subscription)을 보세요.

키를 넣어야 하는 것은 모두 같은 화면 맨 아래의 **고급** 안에 있습니다. 펼치기 전에는 접혀 있습니다.

## 기본은 구독입니다

- **사용할 AI**는 처음에 **자동**입니다. 연결된 Claude 구독을 먼저 쓰고, 없으면 Codex를 씁니다.
- 자동은 요금이 더 나가는 것을 고르지 않습니다. API 키는 **사용할 AI**에서 그 제공업체를 직접 골라 둔 동안에만 쓰입니다.
- AI 패널 아래쪽의 모델 목록에는 구독이 먼저 나오고, 그다음에 설정을 마친 키 방식 제공업체가 나옵니다. 구독 아래의 **기본 모델**은 그 구독의 표준 모델입니다.

## API 키(고급 ▸ AI 모델)

제공업체에 직접 요금을 내고 쓰거나, 직접 운영하는 모델을 쓰려는 분을 위한 곳입니다.

- **제공업체**를 고르고 **API 키**를 넣습니다(제공업체에 따라 **Base URL**도 넣습니다). **모델**을 고른 뒤 **저장**을 누릅니다. 목록에는 OpenAI 호환 서버, Anthropic, Gemini, DeepSeek, DashScope(qwen), Atlas Cloud 등이 있습니다.
- 여기의 **제공업체** 목록은 화면에 어느 쪽 입력란을 보여 줄지만 정합니다. 실제로 쓰는 AI는 바뀌지 않습니다. 그것은 언제나 **사용할 AI**가 정합니다. 저장한 제공업체가 지금 쓰는 AI가 아니면 위쪽에 **이 AI 쓰기**가 나옵니다. 누르면 그 제공업체가 **사용할 AI**가 됩니다.
- 키 방식 제공업체로 하는 대화는 직접 넣은 키를 쓰고, 요금은 그 회사에서 청구됩니다.
- 키는 이 컴퓨터의 앱 설정 파일에 저장되며 요청 헤더에만 실려갑니다.
- **연결 테스트**: 저장하기 전에 엔드포인트 연결과 모델 노출 여부를 확인할 수 있습니다.
- 기본 URL에는 경로와 쿼리 문자열을 넣을 수 있어(게이트웨이 형식) 엔드포인트 경로가 올바르게 이어 붙습니다.
- 직접 운영하는 서버는 **엔드포인트**를 여러 개 저장해 두고 언제든 바꿔 쓸 수 있습니다.
- **Codex 실행 파일**은 Codex 프로그램을 특이한 위치에 설치한 경우에만 씁니다. 비워 두면 프로그램을 자동으로 찾습니다.

## 기능마다 필요한 것

| 기능                                      | 무엇으로 동작하나                                                                                                                                                            |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AI 패널의 대화와 편집                     | 구독, 또는 직접 고른 키 방식 제공업체.                                                                                                                                       |
| 그림 이해하기                             | 대화 중인 AI가 그림을 직접 봅니다. 키가 더 필요하지 않습니다. 분석용 제공업체를 따로 두려면 고급에서 고릅니다.                                                               |
| 그림 만들기                               | **이 버전에서는 키로만 됩니다.** 고급 ▸ AI 미디어 및 검색에서 이미지 제공업체를 설정합니다. 설정한 것이 없으면 이미지 생성을 쓸 수 없고, Slides는 검색한 그림을 대신 씁니다. |
| 동영상·음성 분석                          | 동영상을 지원하는 키 방식 제공업체. 고급 ▸ AI 미디어 및 검색에서 고릅니다.                                                                                                   |
| 웹 검색과 이미지 검색, 주소로 페이지 읽기 | 기본은 키 없이 되는 무료 검색입니다. 검색 제공업체의 키는 넣어도 되고 안 넣어도 됩니다.                                                                                      |
| 내 파일 안에서 찾기                       | 이 컴퓨터에서 돌아갑니다. 결과를 외부 서비스로 재정렬하는 기능은 선택 사항이고 기본은 꺼짐입니다.                                                                            |

**고급 ▸ AI 미디어 및 검색**에서는 같은 제공업체의 키와 Base URL을 한 번만 넣으면, 그 제공업체를 쓰는 모든 기능이 함께 씁니다.

## 변경이 적용되는 시점

- 모델과 엔드포인트 변경은 즉시 적용됩니다. 진행 중인 대화는 다음 회차 전까지 이전 설정을 사용합니다.
